# 02. Talent Passport — основа всего

## Как создать

1. Перейди → [talent.app](https://talent.app/) или [app.talentprotocol.com](https://app.talentprotocol.com)
2. Подключи wallet (**Base** — предпочтительно)
3. Заполни профиль максимально подробно

## Что обязательно заполнить

- Аватар и баннер высокого качества
- Bio (на английском)
- Социальные ссылки (Twitter/X, Farcaster, GitHub, Telegram)
- Местоположение
- Навыки (Skills)

**Совет:** Чем полнее профиль — тем лучше начальный score.

## Полезные настройки

- Включи все возможные интеграции
- Подтверди email и другие аккаунты
