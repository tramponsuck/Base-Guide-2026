# 01. Введение в Builder Score

## Что такое Builder Score?

**Builder Score** (сейчас также называется **Builder Rank**) — это репутационная система от **Talent Protocol**. Она оценивает реальный вклад билдера через:

- On-chain активность
- GitHub вклады
- Верификации (Human Checkmark)
- Credentials и квесты
- Другие данные (Farcaster, deployments и т.д.)

## Почему это важно в 2026 году?

- Еженедельные и ежемесячные **Builder Rewards** от Base
- Приоритет в грантах и акселераторах
- Лучшая видимость для инвесторов и команд
- Возможность получать $TALENT и другие награды

## Текущие ориентиры (2026)

- **< 30** — новичок
- **40–60** — средний уровень
- **70–90** — сильный билдер
- **100+** — топ

**Важно:** Система борется с sybil-атаками. Качество >> количество.
