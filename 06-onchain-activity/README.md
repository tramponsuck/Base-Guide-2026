# 06. On-Chain Activity

Качественная активность на Base сильно влияет на score.

## Самые эффективные действия
- Свапы на Uniswap / Aerodrome
- Добавление ликвидности
- Бридж активов в Base
- Взаимодействие с популярными dApp (Friend.tech, Mirror, Farcaster-related)
- Деплой смарт-контрактов (даже простых)
- Участие в официальных тестнетах / кампаниях Base

**Важно:** Качество > Количество. Избегай бессмысленного wash-trading.

**Рекомендация:** 5–15 осмысленных транзакций в неделю.
