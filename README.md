## Быстрый старт

1. Перейди на [talent.app](https://talent.app/)
2. Создай **Talent Passport**
3. Получи **Human Checkmark**
4. Купи **Basename**
5. Подключи GitHub + сделай активность

**Цели:**
- 40+ — хороший старт
- 70–90+ — сильный результат
- 100+ — топ-билдеры
