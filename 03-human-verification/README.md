# 03. Human Verification (Human Checkmark)

**Самый важный шаг** — даёт большой прирост к score (+20–25 баллов).

## Что такое Human Checkmark?

Это подтверждение, что ты — реальный человек (не бот). Talent Protocol агрегирует данные из надёжных источников.

## Способы получения (актуально на 2026)

1. **Coinbase Verified Account** — один из самых простых
2. **Binance Account Bound (BABT)**
3. **Galxe Passport**
4. **World ID** (через World App)
5. **Другие**: Humanode Biomapper, некоторые KYC-сервисы

**Рекомендация:** Начни с Coinbase или Binance — обычно быстрее всего.

## Пошагово (на примере Coinbase)
1. Верифицируй аккаунт на Coinbase (KYC)
2. Зайди в Talent Passport → раздел Credentials / Quests
3. Найди и выполни верификацию Coinbase
4. Подтверди владение wallet

**Совет:** Делай это с основного кошелька, который будешь использовать дальше.
