# 05. GitHub Integration

GitHub — один из самых сильных факторов для Builder Score.

## Как подключить
1. В Talent Passport → Integrations → Connect GitHub
2. Авторизуй аккаунт

## Как быстро поднять вклад
- Форкай популярные репозитории Base / Talent Protocol
- Делай коммиты (даже небольшие правки: README, документация, баги)
- Создай 2–3 своих репозитория (даже простой гайд вроде этого)
- Делай **регулярные** коммиты (лучше 3–5 в неделю, чем 50 за день)

**Цель:** 20–50+ contributions за 30–90 дней.
