# 10. FAQ и решение проблем

**Q:** Score вообще не растёт?  
**A:** Проверь Human Checkmark + Basename + GitHub. Без них рост медленный.

**Q:** Можно ли фармить много аккаунтов?  
**A:** Риск бана. Лучше один сильный аккаунт.

**Q:** Сколько времени нужно?  
**A:** 40+ баллов — 1–2 недели интенсивно. 70+ — 1–3 месяца.

**Q:** Score упал?  
**A:** Система иногда пересчитывает. Продолжай качественную активность.
