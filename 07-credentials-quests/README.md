# 07. Credentials & Quests

Credentials — это все твои достижения в Talent.

## Приоритетные типы
- **Identity** → Human Checkmark, Basename
- **Activity** → GitHub, On-chain, Account Age
- **Skills** → разные верификации (POAP, Galxe, Layer3)

## Где брать квесты
- Раздел Quests в Talent Passport
- Galxe кампании Base
- Layer3 quests
- Официальные партнёрские квесты

**Совет:** Выполняй всё, что даёт Credential с галочкой.
